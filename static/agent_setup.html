🔧 Agent 安装指南

在其他安装了 AutoCAD 的电脑上运行 Agent，接入分布式标注网络

前提条件

1

安装 Python 3.9+

从 python.org 下载安装，勾选 "Add Python to PATH"

2

安装 AutoCAD

确保本机已安装 AutoCAD 2024 / 2025 / 2026 任一版本

3

安装 Python 依赖

打开命令行，执行：

pip install requests pywin32 Pillow httpx

获取 Agent 程序

4

拷贝文件到本机

将以下文件/文件夹从服务器拷贝到本机同一个目录下：

dwg_agent.py
dwg_processor/
ai_adapters/
recommendation/
⚠ 注意：如果你使用的是共享文件夹方案（推荐），DWG 文件放在网络共享路径（如 \\server\dwg_files），所有电脑都能直接访问，无需拷贝 DWG 文件。

配置并运行

5

修改服务器地址

编辑 dwg_agent.py 顶部，或通过命令行参数指定服务器地址：

python dwg_agent.py http://192.168.1.5:5000

默认连接 http://127.0.0.1:5000

6

启动 Agent

python dwg_agent.py http://192.168.1.5:5000 --name 张三的电脑

启动后会显示 Agent ID、主机名等信息，并自动注册到服务器

7

验证连接

打开服务器网页，左侧应该能看到新增的"工作节点"面板，显示你的电脑在线
